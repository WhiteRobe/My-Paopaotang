# 站姿与末圈 v5.0.2

侧身腿部不再跟随后肩和背包边界定位，改为固定身体中轴；腿部转动点取自大腿上端的实际透明轮廓。检查八名角色的左右站立、走动与停步，避免看起来向前倾斜。

移除主动道具拾取与替换时的说明浮窗，保留道具图标、拾取特效、音效及地上旧道具。

兔子只在正前方遇到单格墙箱、落点可通行时跳跃。正前方有泡泡或落点有泡泡时不得起跳；贴墙角时不能因为相邻行的方块绕过泡泡。图鉴说明同步五种语言。

AI 在窄路全部被未来预警覆盖、没有完全安全格时，会选择能在危险生效前到达的路线，优先保持行进方向。普通无目标巡路也避免每次思考都随机反向。放泡前的逃脱判断仍要求存在完全安全格，不能使用上述退路作为自杀放泡的依据。
