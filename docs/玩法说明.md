# 泡泡糖：像素群岛大冒险

Godot 双人小游戏已扩展为中文的八人对战游戏（真人最多四人）：44 张机关地图、26 种常规道具、8 位可解锁角色、3 种坐骑，以及单人闯关、自由混战、2v2 和五章剧情冒险。保持 1920×1080 渲染，地图与道具使用新 HD 图集。地图为 27×19 格，角色连续移动，四方向每方向十二至十四张独立行走帧。

地图地表、障碍、背景、角色、坐骑和道具图标均为本项目原创像素画。泡泡使用圆形轮廓、高光和膨胀动画。14 首原创主题音乐分别对应海港、森林、冰雪、沙漠、火山、工厂、糖果、星空、沼泽、遗迹、深海、空港、王城和洞窟，每首约两到三分钟。

## 直接开玩

GitHub 仓库不包含导出的程序；请先用 Godot 导入 `project.godot` 运行。以下应用与启动脚本说明适用于本地打包之后。

macOS 上双击 `dist/泡泡糖.app`，或双击 `启动游戏.command`。程序已包含 Godot 运行时，支持 Apple Silicon 和 Intel。压缩包为 `dist/泡泡糖-macOS.zip`。

若系统拦截本地签名的程序，在访达中右键选择“打开”。

启动后进入主菜单，选择游戏模式，再进入对应大厅。上下键选择设置，左右键修改，回车开始；空格打开当前选项。鼠标也可点击。C 打开真人角色选择，混战与组队大厅用 V 浏览地图、R 设为随机。主菜单集中提供设置、快捷键、存档、图鉴、统计与版本入口；F1 查看操作，F2 打开全图鉴，F3 选择语言。

## 模式与组队

| 模式 | 玩法 |
| --- | --- |
| 剧情冒险 PVE | 五章二十节，支持一到四名真人，开启电脑队友时补足四人。包含收集、救援、点灯、护送、守点、波次战和五场 Boss 战。对白用回车继续，ESC 跳过；P 可在对白期间暂停 |
| 单人闯关 | 一名真人依次挑战 20 关。前四关为真人对一个电脑；第五关起总共四人，可开启电脑队友组成 2v2，或关闭队友挑战三个敌人。后面的电脑反应和初始能力会提升 |
| 自由混战 | 两到八个席位，真人数量可选一到四，其余由电脑补足；每人各自为战，先赢两局夺冠 |
| 组队对战 | 四、六或八个席位，组成 2v2、3v3 或 4v4。真人最多四名，其余由电脑补齐；连续席位或交叉分组 |

对战模式可指定地图，也可以按 R 选择随机地图，每局重新抽取。闯关与剧情大厅用左右键切换已解锁关卡；选图快捷键不会改变游戏模式。ESC 从大厅回到模式选择，再返回主菜单。

## 剧情冒险：归航之光

在模式选择页进入“剧情冒险 PVE”大厅，再选真人数量、电脑队友和角色，回车开始。关卡列表仅开放已完成关卡与当前关卡，可回头重温剧情。冒险存档与原有竞技闯关各自保存，旧存档可继续使用。

潮汐核心失窃后，群岛不断下沉。蓝莓和伙伴沿着墨色脚印寻找核心，在每章救回被墨潮控制的居民和守护者，最终重启王城灯塔，让全岛的光击退墨潮。

| 章节 | 四张新地图 | 关底 Boss |
| --- | --- | --- |
| 萤灯沼泽 | 萤灯浅滩、毒蕈小径、旋叶营地、苔冠王庭 | 苔冠树王：十字根须冲击，召唤沼泽怪物 |
| 回声遗迹 | 镜光门廊、尖刺回廊、回声石阵、砂钟圣殿 | 砂钟守卫：横纵十字扫射 |
| 珊瑚深庭 | 珊瑚水巷、旋潮牢湾、潮汐孵化场、铁钳竞技场 | 铁钳蟹将：锁定脚下九格钳击 |
| 风帆空港 | 风帆码头、断桥驿路、云涡观测台、雷翼停机坪 | 雷翼飞艇：三列雷击轰炸 |
| 墨潮王城 | 墨潮外城、暗灯街区、机关兵工厂、核心王座 | 墨潮大王：对角墨潮与机关兵召唤 |

收集任务每人一次携带一件，需运回中央检查点才能计数；救援任务需持续靠近居民一秒；点灯任务按标号依次用水柱命中灯柱；护送任务需要留在车辆三格内，车辆会等待道路畅通，并在三处补给点等待队员靠近充能 1.5 秒，耐久耗尽会失败；守点任务坚持指定时间；波次战清除每波敌人后出现下一波。

任务完成后，需要一位真人走到中央发光的出口才能过关。六种普通怪物各有不同像素造型，部分怪物会瞄准角色释放预警攻击。水柱会削减怪物和 Boss 的生命值，Boss 生命低于一半后攻击加快。冰冻弹也能冻结怪物，诱饵能吸引怪物，换位星可与怪物或 Boss 交换位置。

冒险开局至少三个泡泡、三格水柱和一级泡泡强化，可继续拾取成长与坐骑。真人队伍每关共享两次复苏；电脑队友每关能复苏一次。怪物偶尔掉落心形护盾补给。队友仍可触碰救援被困角色，同队水柱不伤队友，自己的水柱仍会困住自己。

每节开场对白、任务进度、Boss 生命和结尾对白均支持中文、英文、日文、法文和德文。完成一节后保存下一节进度；失败或中途退出可从本节重开。PVE 正常倒计时为 270～300 秒，归零后沿用每五秒一圈的地图坍塌规则。

走到道具上会自动拾取；已有主动道具时，新道具替换旧道具，旧道具留在地上，离开后可以再次拾取。按住 Shift 再按道具键也可手动交换。玩家二也支持数字键盘回车与除号。

## 胜负与救援

泡泡通常在 2.3 秒后爆炸，向四个方向喷出水柱。墙挡住水柱，箱子会被炸开，其他泡泡会连锁引爆。爆炸前约 0.7 秒显示危险范围，踢动泡泡后范围也会随位置改变。

被命中后，角色会困在泡泡里八秒。敌人触碰会使其立即出局；队友触碰可以救援。同队水柱不会伤到队友，但自己放的泡泡仍会伤到自己。护盾、脱困针和急救道具也能脱困。

混战剩下最后一人、组队剩下最后一队时结算。对战地图的正常倒计时为 150～210 秒，大厅地图预览会显示时间。倒计时结束后继续对战，地图每五秒向内坍塌一圈；下一圈提前闪烁预警，地块下落后变成不可通行的深坑，站在坍塌区域会直接出局。平局不增加比分。

## 坐骑与人物

坐骑随角色一起移动，会先承受水柱，耐久耗尽后角色下马。泡泡鸭移动较快，初始能挡一次；甲壳龟较慢，初始能挡两次；跳跳兔可以跳过一格箱子，初始能挡一次。骑术成长可进一步增加耐久。

蓝莓和桃桃初始可用。竞技闯关或剧情冒险通关达到 3、5、8、11、15、20 关时，分别解锁薄荷、柚子、雪球、星芽、机仔、火苗。各人物有不同造型与初始能力，人物选择页会显示说明。TAB 或顶部席位按钮可切换正在配置的真人玩家。电脑角色会按关卡或地图变化。

## 存档与统计

进度、角色解锁、四个玩家的角色选择、大厅设置、声音与语言设置、支线奖章和统计会自动保存。存档位于：

```text
~/Library/Application Support/paopaotang/profile.json
```

统计记录玩家一的局数、胜负、放泡泡、炸箱、拾取、救援、骑乘、出局、中途退出和游戏时长；另外保存队伍击败怪物、击败 Boss 和冒险通关次数。结算、返回大厅或关闭游戏时保存，暂停期间不计时。闯关胜利后推进到下一关，失败可重试；通关二十关后可重新冒险。

## 源码与制作工具

源码仓库不附带 Godot 运行时。请安装 Godot 4.x，导入 `project.godot` 后运行；`编辑工程.command` 是本地开发时使用的辅助脚本，其运行时路径需按自己的安装位置调整。当前程序在 Godot 4.7.2 上验收。

`game.gd` 包含游戏、电脑策略、菜单、统计和存档；`data/catalog.gd` 保存地图、道具、人物与坐骑内容。`adventure.gd` 负责剧情任务、怪物与 Boss，`data/story.gd` 保存五章剧情和对白，`map_mechanisms.gd` 负责新增机关。没有外部运行插件依赖。

重新生成美术、图标与原始音效需要 Python 3 和 Pillow：

```sh
python3 tools/draw_pixel_art.py
python3 tools/create_adventure_art.py
python3 tools/create_assets.py
```

重新制作十四首主题音乐需要 numpy 和 ffmpeg：

```sh
python3 tools/compose_themes.py
```

`assets/audio/themes/catalog.json` 记录音乐名称、节拍和时长。

macOS 重新打包需要 Xcode Command Line Tools、Python 3 和 Pillow：

```sh
python3 tools/build_macos.py /你的路径/Godot.app/Contents/MacOS/Godot
```

打包脚本生成 PCK、编译双架构启动器，随后装入官方 Godot 二进制、资源和授权文件。应用使用本地签名，未做 Apple 公证。其他平台可使用 Godot 对应导出模板另外打包。
