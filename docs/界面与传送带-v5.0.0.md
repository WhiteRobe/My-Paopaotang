# 界面与传送带 v5.0.0

对战地图从 27×19 扩到 31×19，方格保持正方形。地图靠左铺开，右侧集中显示玩家头像、三维、队伍和状态。死亡头像变灰，下方保留最多四名真人的主动道具与使用按键。赛车名次沿用同一栏，剧情仍显示任务进度、复苏次数、首领血条和小地图。

顶部加入太阳到月亮的昼夜表，读取实际昼夜状态，洞窟仍然恒夜。每局开场倒计时结束后，机制说明浮窗显示五秒，随后淡出。暂停菜单为继续对战、重新开始、返回大厅；重新开始清零整场比分并返回首局，移除保存并退出按钮。原有自动存档继续生效。

左右行走改用各角色已有的独立方向整帧动作，手臂随腿部动作变化。所有侧身帧使用统一比例和头部锚点，移动距离驱动播放，避免逐帧缩放造成跳动。元数据制作脚本只测量透明区域，不改动源图像。

传送带可以运输泡泡和地上的道具。每格移动过程插值绘制，墙、箱子、管道侧面及前方泡泡会阻挡运输；道具不覆盖已有掉落。泡泡仍按原倒计时爆炸，采用实际所在格结算水柱。踢动或漩涡改变泡泡位置时，停止旧的传送插值。

验收使用独立临时存档和真实主场景。已检查 44 张对战图的生成和出生点、20 个剧情关卡的生成与首帧推进、重开比分、双向行走、头像灰化、开场浮窗、赛车名次栏以及传送带的泡泡和道具运输。另已查看四名真人的剧情面板和赛车分屏。macOS 安装包签名与压缩完整性检查通过。上述检查不代表所有关卡已经完整通关。过程截图与日志放在 `/tmp/paopaotang-v500-*`，导入和构建报告由 harness 输出。
