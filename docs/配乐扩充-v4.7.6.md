# v4.7.6 配乐扩充

## 游戏中的播放规则

主菜单及通用页面播放《潮汐序曲》，大厅、席位配置及地图预览播放《出航前夜》。在大厅换地图、角色或难度不会反复重启音乐。

地图原曲与新变奏按地图索引和局次交替选择。剧情对白使用地图曲，进入五章首领战后切换对应 Boss 曲；Boss 被击败后恢复地图曲。开局准备乐句优先播放，最后三十秒切换紧张循环，包含 Boss 战。暂停沿用当前场景的配乐。

曲目切换采用 0.45 秒交叉淡化。音乐音量与静音同时控制新旧两个播放器，音效音量仍独立设置。资源按需加载并缓存，游戏运行不需要网络或音频生成工具。

## 制作与检查

全部新增音频由 `tools/audio/compose_music_expansion.py` 原创合成，没有使用外部音频采样。音符、旋律、和声、振荡器与打击乐都在脚本中定义，输出 32 kHz 立体声 OGG。新增目录为 `assets/audio/music/`，制作参数记录在同目录 `catalog.json`。既有十四首主题曲与液体音效不重制。

```sh
python3 tools/audio/compose_music_expansion.py
# 仅重制指定曲目，保留其他音乐和目录条目
python3 tools/audio/compose_music_expansion.py --only forest-alt
```

检查使用隔离存档和真实 Godot，不向项目添加单元测试。全部新增 OGG 完整解码，检查时长、峰值、均方根音量、立体声差异和循环边界；修正森林曲编码后的边界跳变。真实窗口运行检查了二十一首曲目的播放状态与音频总线信号、十四主题两套资源、五章剧情至 Boss 的切换、开局与末段倒计时、暂停、静音、音量归零和交叉淡化。听感仍可通过下方试听与实际游戏判断，这些技术检查不代表主观音乐评价。
