# 资源制作

运行游戏不需要重新生成资源。`assets/` 已含可用图片、音乐、音效和字体。生成器属于开发工具，会覆盖目标文件，修改前先查看 Git 差异，只运行本次需要的脚本。

人物方向顺序为下、上、左、右。行走索引依据透明轮廓发现实际列数，不依赖提示词中的预计帧数；裁切范围限制在当前行，不扩展到相邻行；绘制使用整张人物行走图集的统一比例并对齐脚底。正面受击和放置使用动作图集，其他方向保留整体倾斜反馈。实战骑乘与赛车使用角色、载具一体绘制的整帧动画，保留膝盖、鞍座、方向盘与载具的遮挡关系。骑乘索引按实际透明间隔寻找行列边界，行内共用脚底基线，避免整齐等分切入相邻帧。怪物按待机、左右移动、攻击、受击、倒地六类状态选择动画帧。

已清理停用的早期像素图集、premium 图集及其生成器；当前原图与历史提示词分别保存在 `assets/art/` 和 `docs/art-production/`。更新在用原图后运行：

```sh
python3 -m pip install Pillow numpy
python3 tools/art/index_atlases.py
```

重新索引后检查背面、侧面、骑乘、头像、任务物件，以及图鉴和场景的比例。原图若改变排列，要修改索引规格，避免把相邻角色切进同一单元。

## 音乐与音效

主题原曲放 `assets/audio/music/themes/`，变奏放 `variations/`，Boss 曲放 `boss/`，菜单与大厅曲放 `frontend/`。声音效果放 `assets/audio/sfx/`，开局与末段倒计时曲放 `assets/audio/cues/`。新曲目录 `catalog.json` 的 `file` 字段相对于 `assets/audio/music/`，保留分类路径。

只重制音效时执行：

```sh
python3 tools/audio/create_sfx.py
python3 tools/audio/create_bubble_audio.py
python3 tools/audio/create_round_audio.py
```

最后一个脚本生成强化破泡音效并覆盖旧版本。它们不改主题音乐、人物和地图。无需在普通检查中重新运行生成器。


```sh
python3 -m pip install numpy
python3 tools/audio/compose_themes.py
```

主题音乐制作还需要可用的 `ffmpeg`。脚本生成十四主题 OGG 以及 `assets/audio/music/themes/catalog.json`，每首 256 拍、约 120～183 秒，音色、调式和编曲按主题变化。修改音乐必须听取头尾、循环接缝、战斗中音量与音效叠加；headless 不能完成听觉验收。

## 国际化

游戏使用 `i18n.gd` 加载离线 `locales/en.json`、`ja.json`、`fr.json`、`de.json`；中文直接显示源码文字，`zh.json` 是维护时的原文目录。`loc()` 先匹配整句，未命中时尝试较长的名称片段替换。

```sh
python3 tools/i18n/refresh_translations.py
python3 tools/i18n/polish_locales.py
```

刷新脚本会连接 Google 翻译接口，只补缺失条目；不要在普通 `check` 中调用。翻译后的 `%d`、`%s` 等占位符必须与原文兼容，原文改动后旧键可能还在目录里。先检查差异，再在 F3 语言菜单切换五种语言，看大厅、图鉴、对白和 HUD 是否截字或回退成中文。

## 资源去向与授权

可运行素材与生成器提交到仓库，临时截图和试听中间文件写入 `/tmp`。正式文档只选少量实际引用图片放 `docs/screenshots/`。`.import` 与 `.godot/` 可以再生成；`.uid` 按项目约定忽略，打包后清理。详细规则见 [文件与资源管理](文件与资源管理.md)。

中文使用霞鹜文楷屏幕阅读版，其他语言及缺字回退使用 Noto Sans CJK；原始字体文件保存在 `assets/fonts/`，授权位于 `licenses/`。构建时保留字体与 Godot 的声明文件。不得将引擎运行时或导出应用提交进源码仓库。


当前动作素材来源：怪物 11 张动画图集和人物正面 4×2 图集由内置 imagegen 生成，原始 PNG 原样复制到 `assets/art/` 的对应分类，原文件位置与当前资源路径记录在 `docs/art-production/source-files.json`。完整提示词见 `docs/art-production/monster-animation-prompts.json` 与 `docs/art-production/hero-front-clean-prompt.txt`。索引工具只分析透明像素并记录区域，不改动原图。角色主题色由 `hero_palette.gd` 的独立小视口及 shader 实时渲染，沿用原图细节。
