# 资源制作

运行游戏不需要重新生成资源。`assets/` 已含可用图片、音乐、音效和字体。生成器属于开发工具，会覆盖目标文件，修改前先查看 Git 差异，只运行本次需要的脚本。

## 当前运行素材

当前运行使用 `assets/hd/`，由 `hd_art.gd` 加载 `regions.json` 并缓存图集。素材制作记录见 [HD 制作说明](../assets/hd/GENERATION.md)。所有 PNG 为内置 imagegen 的原始输出，索引脚本只读取透明边界，不修改图像。

| --- | --- |
| `playfield-*-hd.png` | 十四主题，每主题八个正交地面、墙和箱体 |
| `blocks-depth-v463.png` | 八格新箱墙图集，运行使用墙块、木箱、推箱、钢箱、完整与受损宝库；墙块保留十四主题色调 |
| `theme-*-hd.png` | 保留的十六格主题素材，只使用少量边界装饰 |

人物方向顺序为下、上、左、右。行走索引依据透明轮廓发现实际列数，不依赖提示词中的预计帧数；裁切范围限制在当前行，不扩展到相邻行；绘制使用整张人物行走图集的统一比例并对齐脚底。正面受击和放置使用动作图集，其他方向保留整体倾斜反馈。坐骑使用四方向造型与整体起伏。怪物按待机、左右移动、攻击、受击、倒地六类状态选择动画帧。

旧 `premium/` 与详细图集保留用于记录与制作参考，当前显示不再使用旧像素坐标。旧原创生成器会覆盖旧资源，但不能重建当前 HD 图集。更新 HD 原图后运行：

```sh
python3 -m pip install Pillow numpy
python3 tools/index_hd_atlases.py
```

重新索引后检查背面、侧面、骑乘、头像、任务物件，以及图鉴和场景的比例。原图若改变排列，要修改索引规格，避免把相邻角色切进同一单元。

## 生成依赖

安装 Pillow 后可生成图片。当前高分辨率生成器可独立制作对应资源；基础图集与道具合成存在覆盖依赖。

```sh
python3 -m pip install Pillow

# 基础资源：覆盖旧人物、旧地图以及基础道具
python3 tools/draw_pixel_art.py
# 接入剧情旧地图、怪物与任务图标
python3 tools/create_adventure_art.py
# 合成六种核心，重建道具图集与冲击特效
python3 tools/create_effect_art.py
# 最后补上照明弹与火把，必须晚于 create_effect_art.py
python3 tools/create_weather_art.py

# 保留的旧详细素材
python3 tools/create_detailed_world.py
python3 tools/create_detailed_crates.py
python3 tools/create_hero_art.py
python3 tools/create_creature_art.py
python3 tools/create_mount_animation.py

# 图标与音效；独立于主题音乐
python3 tools/create_assets.py
```

`create_crate_art.py` 和 `create_detailed_crates.py` 制作保留的旧箱体素材；当前运行使用 HD 原图。早期背景、人物、箱体与任务素材仍保留，不要为整理目录而直接删除。`create_effect_art.py` 只复制基础道具的前两行，重新运行后必须再执行 `create_weather_art.py`，否则照明道具图标会丢失。

## 音乐与音效

```sh
python3 -m pip install numpy
python3 tools/compose_themes.py
```

主题音乐制作还需要可用的 `ffmpeg`。脚本生成十四主题 OGG 以及 `assets/audio/themes/catalog.json`，每首 256 拍、约 120～183 秒，音色、调式和编曲按主题变化。修改音乐必须听取头尾、循环接缝、战斗中音量与音效叠加；headless 不能完成听觉验收。

## 国际化

游戏使用 `i18n.gd` 加载离线 `locales/en.json`、`ja.json`、`fr.json`、`de.json`；中文直接显示源码文字，`zh.json` 是维护时的原文目录。`loc()` 先匹配整句，未命中时尝试较长的名称片段替换。

```sh
python3 tools/refresh_translations.py
python3 tools/polish_locales.py
```

刷新脚本会连接 Google 翻译接口，只补缺失条目；不要在普通 `check` 中调用。翻译后的 `%d`、`%s` 等占位符必须与原文兼容，原文改动后旧键可能还在目录里。先检查差异，再在 F3 语言菜单切换五种语言，看大厅、图鉴、对白和 HUD 是否截字或回退成中文。

## 资源去向与授权

可运行素材与生成器提交到仓库，临时截图和试听中间文件写入 `/tmp`。正式文档只选少量实际引用图片放 `docs/screenshots/`。`.import` 与 `.godot/` 可以再生成；`.uid` 随源码保留。详细规则见 [文件与资源管理](文件与资源管理.md)。

字体使用缝合像素字体，授权位于 `assets/fonts/` 和 `licenses/`。构建时保留字体与 Godot 的声明文件。不得将引擎运行时或导出应用提交进源码仓库。


当前动作素材来源：怪物 11 张动画图集和人物正面 4×2 图集由内置 imagegen 生成，原始 PNG 原样复制到 `assets/hd/`，原文件位置记录在 `source-files.json`。完整提示词见 `monster-animation-prompts.json` 与 `hero-front-clean-prompt.txt`。索引工具只分析透明像素并记录区域，不改动原图。角色主题色由 `hero_palette.gd` 的独立小视口及 shader 实时渲染，沿用原图细节。


v4.7.0：PVE 高压核心原图由内置 imagegen 制作，提示词与来源见 [资源记录](../assets/hd/GENERATION.md)。统一遮挡修正不重新生成原有贴图。


v4.7.1：`tools/create_bubble_audio.py` 只生成 `assets/audio/bubble-trap.wav` 与 `bubble-pop.wav` 两种原创液体短音效，不覆盖主题音乐。全局裁切仅更新 `regions.json` 及绘制规则，不修改 PNG 原像素。


v4.7.2：新增 `tools/create_round_audio.py`，只生成强化的 `bubble-pop.wav`、开局 `round-ready.wav` 和 32 秒紧张循环 `round-urgent.wav`。如果同时重制旧液体音效，先执行 `create_bubble_audio.py`，再执行 `create_round_audio.py`。不覆盖既有主题音乐。机关使用 `assets/hd/mechanisms-v472.png`，提示词与来源见同目录制作记录。
